# cause (harness): the test read the operator log ONCE, 8s after releasing the barrier, from the CURRENT container. Locally the container sat in the restart backoff long enough for the terminated container's log to still be returned. Fixed in the harness by polling for the fence across the restart (kubectl logs --previous once restartCount moves); operator image unchanged.
