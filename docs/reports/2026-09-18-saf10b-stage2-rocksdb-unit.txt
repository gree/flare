=== a false alarm worth recording ===
An intermediate run showed test_swap_in_snapshot_clears_corruption_latch failing and several others failing with
"storage_set_string -> -1". Cause: the cutter test modules statically embed libflare objects, so a test module
built against the new header while carrying older embedded objects reads members at the wrong offsets (a counter
read back as 57043968). `make -C test/lib clean` before rebuilding removes it. The library's behaviour was correct
throughout — instrumented runs showed the corrupt batch returning a Corruption status as before. Recorded because
the same shape could otherwise be mistaken for a regression in CI.
