=== regression run 2 (operator 2379cff — follower-reading completeness + END-terminated probes; raw: docs/reports/2026-09-20-saf10-regression-run2-raw.log) ===
command: flare_e2e --filter replica-repair,operator-restart,failover,read-balance,prepare-evidence      RESULT: PASS (30 tests, 0 failures)
Root causes of regression run 1: (1) ReplicaRepair.FollowReading treated a COMPLETE stats reply without follower keys (tch) as
unreadable, so every drop on a tch replica was held as "follower state unknown" and never repaired (replica-repair 3-6);
(2) Bridge.queryPodStats waited out a 3 s timeout per probe, so with the extra per-node probes a 2-node reconcile took 18-31 s,
the stats pass ran every tick and the restarted operator was too slow to re-serve its map before the flared pods' readiness
failed (operator-restart 18-19). Both fixed in 2379cff: probes now take ~0.5 s ("continuous-replication probe: 2 stats read(s)
in 1117ms"); the slowest tick in this run was 7710 ms (24 "reconcile slow" lines over 5 suites, all during repairs/restarts).
