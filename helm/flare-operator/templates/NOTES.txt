The Flare Operator has been deployed to namespace: {{ .Values.namespace }}

To check the operator status:

  kubectl get deployment {{ include "flare-operator.fullname" . }} -n {{ .Values.namespace }}
  kubectl logs -n {{ .Values.namespace }} -l app.kubernetes.io/name={{ include "flare-operator.name" . }} -f

To create a FlareCluster:

  cat <<EOF | kubectl apply -f -
  apiVersion: flare.gree.net/v1alpha1
  kind: FlareCluster
  metadata:
    name: my-flare-cluster
    namespace: default
  spec:
    partitions: 2
    replicas: 2
  EOF

To view FlareCluster resources:

  kubectl get flareclusters -A
